# @educorvi/vue-json-forms-builder-orpc-contract

Shared oRPC contract for the form-builder backend API.

This package contains the single source of truth for the API contract ( currently consumed by backend app, collab server and standalone frontend package).

- `src/generated/` — procedures + zod schemas generated by [`@hey-api/openapi-ts`](https://heyapi.dev) from `docs/api-development.yaml`.
- `src/contract-with-errors.ts` — the enhanced `appContract` with typed error responses (`.errors({...})`). `@hey-api/openapi-ts` does not generate error types, so this wrapper adds them manually.
- `src/contract.ts` — the plain grouping without error types.

See [docs/README.md](./docs/README.md) for the API documentation and the
code-generation workflow.

## Usage

```ts
import { createORPCClient, ORPCError } from '@orpc/client';
import { OpenAPILink } from '@orpc/openapi-client/fetch';
import type { JsonifiedClient } from '@orpc/openapi-client';
import type { ContractRouterClient } from '@orpc/contract';
import { appContract } from '@educorvi/vue-json-forms-builder-orpc-contract';

const client = createORPCClient(
    new OpenAPILink(appContract, {
        url: 'https://backend.example.com/api/v1',
        headers: () => ({ authorization: 'Bearer ...' }),
    })
);

try {
    const me = await client.users.me();
} catch (err) {
    if (err instanceof ORPCError && err.code === 'UNAUTHORIZED') {
        // typed error code from the contract
    }
}
```

## Regenerating the contract

The OpenAPI spec (`docs/api-development.yaml`)
is the source of truth. After changing it, regenerate:

```sh
yarn workspace @educorvi/vue-json-forms-builder-orpc-contract orpg:generate
```

| `@educorvi/vue-json-forms-builder-orpc-contract/contract-with-errors` | enhanced contract               |
