# vue-json-forms-builder-db-layer

A small package that provides a database layer for the Vue JSON Form Builder. Since both the [vue_form_builder](apps/json_forms_builder) and the [collab-server](../apps/collabserver) use this database layer, we can use the definitions for both backend and collab server without relying on imports form the collab server to thr backend app.
